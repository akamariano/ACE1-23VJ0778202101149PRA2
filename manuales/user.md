## Introducción

Bienvenido al manual de usuario de la aplicación para un sistema de Punto de Venta. Esta aplicación ha sido desarrollada en ASM y tiene una interfaz en consola en la cual el usuario puede interacrtuar, así también poder visualizar los reportes en otros formatos.

## Requisitos del Sistema

Para utilizar esta aplicación web necesitarás:
1. Un dispositivo con sistemas operativos antiguos como MS-DOS o versiones muy antiguas de Windows, como Windows 3.1. Estos sistemas operativos son capaces de ejecutar programas de 16 bits

2. Un emulador o máquina virtual como DOSBOX con sus configuraciones necesarias para un montaje virtual
